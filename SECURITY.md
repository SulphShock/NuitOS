# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in NuitOS, please report it responsibly.

**Contact:** Open a private security advisory at https://github.com/SulphShock/NuitOS/security/advisories/new

Do not open a public issue for security vulnerabilities.

## Scope

This policy covers the NuitOS repository only — ISO build scripts, configuration files, and installer tooling. It does not cover third-party packages from the Arch Linux or AUR repositories.

## Response

We will acknowledge receipt within 72 hours and provide a timeline for resolution.
