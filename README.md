# NuitOS

A Hyprland-based Linux desktop configuration.

## Structure

```
NuitOS/
├── configs/          # Application configs
│   ├── hyprland/
│   ├── waybar/
│   ├── kitty/
│   ├── zsh/
│   ├── neovim/
│   └── rofi/
├── scripts/          # Setup and utility scripts
└── pkgs/             # Package lists
```

## Installation

```bash
git clone https://github.com/SulphShock/NuitOS.git
cd NuitOS
./scripts/install.sh
```
